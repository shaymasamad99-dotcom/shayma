# أمان البيانات (Google Play) وخصوصية App Store

أجوبة جاهزة للاستمارة، حسب الكود الحالي.

| النوع | بنجمعو؟ | ليش | بيتشارك؟ | إجباري؟ |
|---|---|---|---|---|
| الإيميل | إي | الحساب | لا | إي (للحساب) |
| الاسم | إي | الترحيب | لا | لا |
| معلومات صحّة ولياقة (تمارين، قياسات، خطوات، أكل، مكمّلات) | إي | وظيفة التطبيق | لا | لا |
| الدورة الشهرية | إي (إذا استعملتيها) | وظيفة التطبيق | لا | لا |
| العمر، الوزن، الطول | إي | تظبيط البرنامج | لا | إي |
| صور | لا (بتضلّ عالجهاز) | | | |
| الموقع، جهات الاتصال، إعلانات، تتبّع | لا | | | |

- البيانات **مشفّرة** وهي عم تنبعت (HTTPS).
- المستخدمة **بتقدر تمسح** حسابها وبياناتها من جوّا التطبيق.
- الخدمة اللي بتحفظ: Google Firebase (Authentication + Firestore).
- رابط سياسة الخصوصية: `privacy.html` (بعد ما ينحط عالموقع).
