# For Me: تحضير التطبيق للمتجر والاشتراكات

كل شي هون جاهز من هلّق. الشي الوحيد اللي بيحتاج مصاري هو حسابات المتاجر، ومنعملها لمّا تقرّري.

| الملف | شو فيه |
|---|---|
| `listing.md` | اسم التطبيق، الوصف القصير والطويل (عربي وإنكليزي)، الكلمات، الفئة، والصور المطلوبة |
| `data-safety.md` | أجوبة استمارة «أمان البيانات» عند Google Play وخصوصية App Store |
| `premium-plan.md` | شو ببلاش وشو بالاشتراك، اقتراح الأسعار والتجربة المجانية |
| `shushy-origin.md` | دليل إنّك إنتِ عملتي شخصية شوشي (التواريخ والملفات) |
| `../privacy.html` | صفحة الخصوصية (عربي + إنكليزي) |
| `../terms.html` | شروط الاستعمال والتنبيه الصحّي (عربي + إنكليزي) |

## ناقص منك (لما يجي الوقت)
1. **إيميل تواصل** للتطبيق، وبحطّو مكان `[إيميل التواصل]` بصفحتي الخصوصية والشروط.
2. **Google Play:** حساب مطوّر (٢٥$ مرّة وحدة) + هويّة، و١٢ شخص يجرّبوا ١٤ يوم.
3. **App Store (إذا بدّك):** حساب Apple Developer (٩٩$ بالسنة) + Mac أو خدمة بناء أونلاين.
4. **الدفع:** منختار شركة الدفع حسب البلد اللي بتستلمي فيه المصاري، وحساب بنكي باسمك.
5. **العلامة التجارية:** تسجيل اسم For Me واللوغو بالبلد اللي رح تبيعي فيه (بنصح بمحامي).

## الخطوات التقنية (عليّ)
- تطبيق Android بنفس طريقة نسخة الآيفون الموجودة (`native/`).
- ربط الاشتراكات بالحساب، وقفل ميزات «Pro» حسب `premium-plan.md`.
- صور المتجر من التطبيق نفسو.
