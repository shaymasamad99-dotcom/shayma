# ببلاش أو بالاشتراك (اقتراح)

## ببلاش
- البروفايل وجدول أسبوعي أساسي (لحد ٣ أيام بالأسبوع)
- التمارين مع الرسومات والخطوات
- تمطيط حسب المنطقة (٥ دقايق)
- سجل التمارين

## For Me Pro
- البرنامج الشخصي اللي بيتطوّر بالمراحل (تأسيس ← تكرار ← وزن ← خفيف) والأوزان المقترحة
- كل فيديوهات شوشي
- أيام لا محدودة، تمرين إضافي ذكي وتصميم تمرين خاص
- الأكل والبروتين والمي
- متابعة الدورة ونصايح التمرين حسب المرحلة
- التقارير الأسبوعية، الأسابيع القديمة والتقويم
- تمطيط أطول ورووتينات جاهزة

## الأسعار (للتجربة، منغيّرن حسب البلد)

- سنوي: ~٢٩.٩٩$ (توفير ٥٠٪)
