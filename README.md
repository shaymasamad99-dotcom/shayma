# تمريني · Tamrini

عربي وEnglish: بدّلي اللغة من زر فوق «برنامجي» أو من «حسابي».

تطبيق ويب بسيط للتمارين (ملف واحد `index.html`):

- **حسابي:** عبّي اسمك، عمرك، وزنك، هدفك ومستواكِ، واختاري كم يوم بالأسبوع (التطبيق بيقترح الأيام وفيكِ تغيّريها، ولكل يوم: تمرين أو سباحة)، والمعدات، والتطبيق بيعملك **جدولي الأسبوعي**: كل يوم شو تمارينه وكم مجموعة × تكرار، وأيام الراحة. بينفتح أي يوم منو، وفيكِ تطبعيه أو تحفظيه PDF. ومن هون كمان اللغة وشكل التطبيق.
- **برنامجي:** كل يوم منوّع وشامل وفيه كور (نوعين مختلفين: ثبات + كرنش أو لف)، وكل عضلة بحركات مختلفة (ضغط + فتح للصدر، سحب عامودي + أفقي للظهر، هيب ثرست + طعنات + عزل للأرداف). برنامج أسبوعي بيتظبط حسب عدد الأيام (جسم كامل، علوي/سفلي، أو دفع/سحب/رجلين)، مع مجموعات وتكرار وراحة حسب الهدف. فيكِ تغيّري المعدات لكل يوم وتبدّلي أي تمرين.
- **رسمة متحرّكة لكل حركة:** بنت عم تعمل التمرين (سكوات، هيب ثرست، بلانك…) بدائرة كبيرة بوضع التمرين، وبتفاصيل كل تمرين. وزر «فيديو الشرح» بيشغّل فيديو يوتيوب جوّا التطبيق لمّا ينفتح كموقع، وإلّا بيفتح عاليوتيوب.
- **ابدئي التمرين:** زر ثابت تحت بيمشّيكِ تمرين تمرين: المجموعة كم من كم، الوزن، عدّاد راحة (بيرن ويهزّ لمّا يخلص)، عدّاد للبلانك والثبات، وملخّص بالآخر. الشاشة بتضل مضوية، والتمرين بيكمل إذا سكّرتي التطبيق.
- **شكل الروتين:** دائرة لكل تمرين فيها جسم حقيقي بعضلات مرسومة (من قدّام أو من ورا) والعضلة اللي بيشتغل عليها ملوّنة بالضبط (⇄ = لكل جهة)، − و + لعدد المجموعات، ومدة التمرين التقريبية. وفي فاتح/غامق/تلقائي من «حسابي».
- **تمريني اليوم:** علّمي ✓ عكل تمرين بتخلّصيه وسجّلي الوزن اللي رفعتيه (مع «المرة الماضية» و«أحسن وزن»).
- **تقدّمي:** كم تمرين خلّصتي بكل أسبوع (آخر ٨ أسابيع)، أيام التمرين مقابل هدفك، سلسلة الأسابيع، وخط تطوّر الوزن لكل تمرين.
- **برنامج بيتطوّر كل أسبوع:** دورة ٤ أسابيع (تأسيس، زيدي تكرار، زيدي وزن، أسبوع خفيف) وبتعيد بأوزان أعلى. لكل تمرين وزن بداية مقترح حسب مستواكِ ووزنك وهدفك، وكل أسبوع بيقلّك قدّيش ترفعي حسب آخر شي سجّلتيه. الثبات (بلانك…) والسباحة كمان بيزيدوا.
- **مرونة كل يوم («شو خطتك اليوم؟»):** رح اتمرّن · سباحة أو كارديو (سباحة، مشي، ركض، دراجة، يوغا/بيلاتس مع الدقايق) · مش اليوم، أجّليه لليوم اللي بعدو (والتمارين اللي بعدو بيترحّلوا معو). بيوم الراحة: «بدّي اتمرّن اليوم» بيجيب التمرين الجايي أو بيعوّض تمرين فات. وفي زر «رجّعي الجدول الأصلي».
- **باقات:** الأيام علوي وسفلي (أو جسم كامل لـ ١–٣ أيام)، ولكل يوم باقات تختاري منها (سفلي: أرداف وشد، فخاد وسمانة، متوازن، بالبيت · علوي: متوازن، ظهر وكتاف، صدر وإيدين، بالبيت · جسم كامل: كلاسيك، مع تركيز أرداف، بالبيت)، وكلّن فيهن كور. «غيّري التمرين» بيورجيكِ بدائل لنفس العضلة، واختيارك بينحفظ.
- **روتينات جاهزة (تمارين قوة حقيقية):** أرداف بالجيم، أرداف بالبيت، بطن سريع، بطن وخصر بالجيم، سمانة ورجلين، رجلين بالجيم، علوي بالدمبل، جسم كامل بالبيت. كل واحد بيفتح بصفحته مع − و+ وزر «ابدئي».
- **التمارين:** تصفّحي حسب المنطقة (الأرداف والبطن والسمانة أول شي)، أو بلا معدات، أو بحث. مكتبة فيها ٩١ تمرين (منها ١٦ للأرداف، ٧ للسمانة، و١٩ للبطن)، بحث بالعربي حسب منطقة الجسم (صدر، ظهر، فخد، بطن…)، وكل تمرين معه شرح خطوات ونصيحة وفيديو شرح محدد عاليوتيوب.

## التشغيل
افتحي `index.html` بأي متصفح. البيانات بتنحفظ عالجهاز (localStorage).

## المراجع
نطاقات المجموعات والتكرار مأخوذة من التوصيات العامة لـ ACSM وNSCA لتمارين المقاومة.
