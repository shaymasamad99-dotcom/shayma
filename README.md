# تمريني

تطبيق ويب بسيط للتمارين (ملف واحد `index.html`):

- **ملفي:** العمر، الوزن، الهدف، المستوى، أيام التمرين، والمعدات (دمبل / ماشين / التنين).
- **برنامجي:** برنامج أسبوعي بيتظبط حسب عدد الأيام (جسم كامل، علوي/سفلي، أو دفع/سحب/رجلين)، مع مجموعات وتكرار وراحة حسب الهدف. فيكِ تغيّري المعدات لكل يوم وتبدّلي أي تمرين.
- **التمارين:** مكتبة فيها ٤٩ تمرين، بحث بالعربي حسب منطقة الجسم (صدر، ظهر، فخد، بطن…)، وكل تمرين معه شرح خطوات ونصيحة وزر فيديو.

## التشغيل
افتحي `index.html` بأي متصفح. البيانات بتنحفظ عالجهاز (localStorage).

## المراجع
نطاقات المجموعات والتكرار مأخوذة من التوصيات العامة لـ ACSM وNSCA لتمارين المقاومة.
